# Linux File Copy Benchmarks

A collection of Linux file-copy implementations using different I/O techniques.

## Implementations

- [x] mmap
- [x] Parallel mmap
- [ ] read/write
- [ ] pread/pwrite
- [ ] readv/writev
- [ ] preadv/pwritev
- [ ] Parallel preadv/pwritev

## Goal

Compare performance, scalability, and implementation complexity of Linux file-copy APIs.
